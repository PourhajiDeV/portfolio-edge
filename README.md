# ☕ منوی دیجیتال کافه و رستوران | EDGE CAFE

یک وب-اپلیکیشن (PWA-Ready) منوی دیجیتال فوق‌العاده مدرن، سریع و کاملاً ریسپانسیو که با الهام از زبان طراحی **iOS 17 (Apple Design Language)** و افکت‌های **Glassmorphism** پیاده‌سازی شده است. 

این پروژه دارای یک **استودیو شخصی‌سازی زنده (Pro Design Studio)** است که به کاربر یا مدیر کافه اجازه می‌دهد تمامی بخش‌های ظاهری از جمله تم، رنگ‌بندی، زوایا و ابعاد کارت‌ها را بدون نیاز به کدنویسی تغییر دهد.

---

## 🌟 ویژگی‌های کلیدی (Key Features)

* **🎨 استودیو دیزاین زنده (Live Customizer Studio):**
  * **Color Picker زنده:** قابلیت تغییر Accent Color با پشتیبانی از تمامی رنگ‌های RGB/HEX.
  * **تم‌های پیش‌فرض پریمیوم:** مشکی عمیق (Pitch Dark)، خاکستری شیشه‌ای، سرمه‌ای تاریک و تم روشن مینیمال.
  * **تنظیم ابعاد کارت‌ها:** تغییر نسبت تصویر (۱:۱ مربع، ۱:۱.۲ استاندارد، ۱:۱.۸ واید سینمایی).
  * **تغییر شعاع زوایا (Border Radius):** انتخاب حالت گرد (Apple Style)، کلاسیک یا تیز.
* **📱 ۱۰۰٪ ریسپانسیو و بهینه‌شده برای موبایل:**
  * پشتیبانی کامل از واحدهای جدید CSS مانند `dvh` (Dynamic Viewport Height) جهت جلوگیری از بریدگی صفحه در مرورگرهای موبایل.
  * هدر شناور مینیمال (Floating Island Header).
  * نوار دسته‌بندی با اسکرول افقی بسیار روان و بهینه‌شده برای لمس (Touch-Friendly).
* **🔍 جستجو و فیلتر آنی:**
  * فیلتر سریع محصولات بر اساس دسته‌بندی.
  * سیستم جستجوی لحظه‌ای (Instant Search) در عنوان و توضیحات آیتم‌ها.
* **🛒 سبد خرید هوشمند و ثبت سفارش:**
  * نوار سبد خرید شناور با محاسبات زنده فاکتور.
  * قابلیت اتصال مستقیم به **واتساپ (WhatsApp Order)** برای ارسال خودکار ریزفاکتور به مدیریت کافه.
* **⚡ عملکرد و سرعت (Performance):**
  * ساخته شده با Pure HTML5, CSS3, Vanilla JS (بدون نیاز به کتابخانه یا فریم‌ورک سنگین خارجی).
  * فونت وزیرمتن (Vazirmatn) لود شده از Google Fonts.
  * بارگذاری بهینه تصاویر با قابلیت `lazy loading`.

## 🛠️ تکنولوژی‌های استفاده شده (Tech Stack)

* **HTML5:** ساختار سمانتیک و بهینه‌شده برای SEO.
* **CSS3 (Modern CSS):** CSS Variables, Flexbox, Bento Grid, Backdrop Blur, Glassmorphism, CSS Animations.
* **JavaScript (ES6+):** مدیریت وضعیت سبد خرید (State Management)، فیلتر داینامیک، دستکاری DOM و کنترل استایل‌های ریشه (CSS Root Variables).
